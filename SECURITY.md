# Security Policy

## Vulnerability Disclosure

We take security seriously and welcome responsible disclosure of vulnerabilities.

### Reporting

If you discover a security vulnerability, please report it to us at:
**security@greenlane.io**

### What to Include

When reporting a vulnerability, please include:

1. A description of the issue and its impact
2. Steps to reproduce the vulnerability
3. Any evidence or proof-of-concept code
4. Your contact information (optional, but encouraged)

### Our Commitment

- We will acknowledge receipt of your report within 48 hours
- We will investigate and provide a status update within 7 days
- We aim to resolve reported vulnerabilities promptly
- We will credit responsible discoverers unless they prefer to remain anonymous

### Responsible Disclosure Guidelines

- Do not exploit the vulnerability beyond what is necessary to verify it
- Do not access or modify data belonging to third parties
- Do not disclose the vulnerability publicly until it has been patched
- Give the project maintainers a reasonable amount of time to fix the issue before any public disclosure

### Supported Versions

We actively support the latest release of GreenLane. Security fixes are backported when feasible.
